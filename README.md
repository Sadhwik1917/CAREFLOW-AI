# CAREFLOW AI

CAREFLOW AI is a web-based Clinic Operations & Patient Management Platform that helps clinics manage their daily operations, patient workflows, clinical activities, billing, and AI-assisted tasks from a unified platform.

## Product Vision

CAREFLOW AI aims to simplify clinic operations by connecting:

- Clinic owners
- Doctors
- Staff
- Patients

into one secure, multi-tenant platform.

## Business Model

CAREFLOW AI is a B2B SaaS platform.

- Clinic owners are CAREFLOW customers.
- Patients are customers of the clinic.
- Clinic owners pay CAREFLOW for using the platform.
- Patients pay the clinic separately for healthcare services.

## Technology

- Frontend: React + TypeScript
- Backend: Node.js
- Database: Firebase Firestore
- Authentication: Firebase Authentication
- AI: Gemini
- Storage: Firebase Storage
- Version Control: GitHub

## Development

The `main` branch contains stable code.

The `develop` branch is used for integration.

Feature development is performed using:

`feature/<feature-name>`

All production changes must go through pull requests.

## Project Status

CAREFLOW AI is currently in the foundation and MVP development phase.
